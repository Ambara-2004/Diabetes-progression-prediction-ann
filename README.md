# Diabetes Progression Prediction Using ANN

## Objective
To predict diabetes progression using an Artificial Neural Network (ANN) and the Scikit-learn Diabetes dataset.

## Dataset
- Source: Scikit-learn
- 442 patient records
- 10 input features
- Target: Diabetes progression measure

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- TensorFlow/Keras
- Jupyter Notebook

## Project Workflow
1. Load and explore the dataset.
2. Check missing values and preprocess the data.
3. Perform Exploratory Data Analysis (EDA).
4. Normalize features and split the dataset.
5. Build and train the ANN model.
6. Evaluate using MSE and R² score.
7. Experiment with an improved ANN architecture and compare results.

## Conclusion
This project demonstrates how an Artificial Neural Network can be used for regression to predict diabetes progression and how different model architectures can affect performance.
